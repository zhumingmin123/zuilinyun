把你自己生成的「水墨风半身人物立绘」放到本文件夹，游戏会自动加载并替换内置的水墨剪影立绘。
（多文件版：与 index.html 同级；直接把 PNG 放进 portraits/ 文件夹即可，刷新页面生效）

  mugui.png        慕归（清冷医女）
  lengji.png       冷寂（热血侠客）
  suqianyu.png     苏浅语（北阙长公主）

  fangni.png       方逆（摄政王）

建议尺寸：竖版半身像，约 3:4（例如 768×1024 或 900×1200），背景留白或水墨渐变。
